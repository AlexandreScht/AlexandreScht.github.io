Règles de confidentialité — Omarchy Calendar

Utilisation

Omarchy Calendar est une application à usage strictement personnel.

Accès aux données

Un script exécuté localement sur l'ordinateur du propriétaire accède à Google Agenda via l'API Google Calendar (scope calendar.events) uniquement pour lire, créer, modifier et supprimer les événements de son propre agenda.

Stockage et transmission des données

Les jetons d'accès et les données restent stockés sur cet ordinateur. Aucune donnée n'est collectée, transmise à un tiers, vendue ni utilisée à d'autres fins.

Révocation d'accès

L'accès peut être révoqué à tout moment sur https://myaccount.google.com/permissions.

Conformité

L'utilisation des données est conforme à la Google API Services User Data Policy, y compris les exigences d'usage limité (Limited Use).
